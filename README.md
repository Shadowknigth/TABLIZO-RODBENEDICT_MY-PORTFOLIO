Project title:
Tablizo_MyPortfolio

Short description:
My website that contains my information that the clients can see about my works, academic information and can contact me.

How to run locally:
Download folder named Tablizo_MyPortfolio
then Open it into VS Code Studio
Inside of MyPage folder
Go to the "index.html"
If you have Live Server Extension, you can proceed to click the "Go Live" below.
Then it will open up the website.
